URBANIA - DEPLOY, SPEED & SEO NOTES
1. Upload the CONTENTS of this folder (not the folder itself) to the root of urbaniajaipur.in (index.html, 404.html, sitemap.xml, robots.txt, manifest.webmanifest, assets/, .htaccess, _headers). HTTPS is required.
2. Every destination, package and vehicle has its own clean URL (e.g. /rajasthan/jaipur, /packages/jaipur-2-days-1-night, /fleet/innova) with its own title, description, canonical, Open Graph/Twitter tags, hreflang and JSON-LD (TravelAgency, WebSite, FAQPage, BreadcrumbList, TouristDestination, TouristTrip, ItemList, Service).
3. sitemap.xml lists all pages with image entries. In Google Search Console: add the property, submit https://urbaniajaipur.in/sitemap.xml, then request indexing of the home page.
4. Create and verify a Google Business Profile for the Jaipur business with the same name, phone and website; this matters most for local searches.
5. Add genuine customer reviews only when you have them; fake review markup is penalised.
6. Speed: images are WebP, videos are muted 960x540 and load only when scrolled into view, the curtain intro runs about 1.3s and can be skipped, fonts load without blocking. Keep gzip/brotli and long cache headers enabled (.htaccess / _headers included).
7. To change content or add photos, edit the data/assets and rebuild; ask Claude to regenerate this folder.
